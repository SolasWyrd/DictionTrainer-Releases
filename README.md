# Чётко — публичные APK

Этот репозиторий содержит только публичные установочные APK, контрольные суммы и release notes.

Исходный код разрабатывается в отдельном приватном репозитории.

## Установка

Откройте раздел **Releases**, скачайте APK последней версии и разрешите Android установку приложений из выбранного браузера или файлового менеджера.

Начиная с версии `0.3`, приложение само проверяет и загружает новые APK из этого репозитория. Android по-прежнему показывает системное окно и требует подтверждения установки.

Приложение не запрашивает микрофон, контакты, пользовательские файлы или местоположение. Интернет используется только для проверки и загрузки обновлений.
